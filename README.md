# SEO MCP Server

一个用于生成 SEO 页面内容的 MCP Server。

## 安装

```bash
npm install @euniii/seo-mcp-server
```

## 功能说明

### generateSeoPage 工具

- **输入**: keyword（字符串，SEO 关键词）
- **输出**: JSON 格式，包含 title、description 和 markdownContent

## 开发

### 安装依赖

```bash
npm install
```

### 构建项目

```bash
npm run build
```

### 启动 Server

开发模式（自动重启）：
```bash
npm run dev
```

生产模式：
```bash
npm start
```

## 在 Trae 中配置 MCP Server

在 Trae 的配置文件中添加此 MCP Server 即可使用。
